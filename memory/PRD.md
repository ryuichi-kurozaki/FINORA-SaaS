## 変更履歴（最新）
- 2026-06: 【機能追加】Transactions（取引履歴）画面で楽天証券「取引履歴CSV(tradehistory)」を各取引レコードとして取り込めるように対応。従来は楽天CSVの自動判定が `entity == "assets"` のみで、取引履歴画面では汎用CSVパーサに落ちて「ファイルを読み込めませんでした」で失敗していた。`io_routes._rk_tx()` を追加し、`entity == "transactions"` かつ `rakuten_format == "history"` のとき各行を transactions（date/tx_type(買付→buy・売却→sell)/quantity/unit_price/amount/fee/currency/notes=ファンド名）へマッピングして挿入。顧客本人のみ実行可（transactions=OWNED、`check_write`）。実データ th1.csv で25件取り込み成功を確認。
- 2026-06: 【確認・仕様確定】楽天証券CSVインポート（取引履歴・保有残高）は「顧客(client)本人のみ」が実行可能。コンサル/管理者はインポート不可（資産はOWNED=顧客専用データ、`check_write`で403、UI上もボタン非表示）。ユーザー要望「コンサル/管理者にいらない・顧客に必要」に一致。実データ検証: 顧客で th1.csv(取引履歴12件)/ab.csv(残高11件) 取り込み成功、スタッフは全行403、他テナントは403。フロント `EntityManager.jsx` の取り込み/価格更新/追加ボタンは `canWrite = canEdit("assets") = isClient` で顧客のみ表示。`/app/backend/io_routes.py` は既存の`check_write`挙動を維持（変更なし）。
